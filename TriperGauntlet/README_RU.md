# Triper Gauntlet — проект Fabric для Minecraft Java 26.2

## Статус

Это исходный проект и папки ресурс-/датапака, а не проверенный готовый JAR. Среда, в которой архив подготовлен, имеет только Java 21, не имеет Gradle и не может разрешать внешние домены, поэтому я не смог выполнить Gradle-сборку. Для Minecraft 26.2 нужен Java 25 и загрузка зависимостей Gradle/Fabric.

## Состав
- `mod/` — исходники Fabric-мода: регистрирует Triper Gauntlet и блок Чёрной субстанции; ПКМ со звездой Незера во второй руке добавляет заряд, ПКМ без звезды расходует заряд. Снаряд не создаётся.
- `resourcepack/` — определения моделей и блок-модель. Замените заглушку текстуры `triper_gauntlet.png` своей текстурой из Blockbench.
- `datapack/` — рецепты и loot table блока.

## Сборка мода
1. Установите JDK 25.
2. Откройте папку `mod` в IntelliJ IDEA как Gradle-проект.
3. Дайте Gradle скачать зависимости из Fabric Maven/Gradle Plugin Portal.
4. Выполните `gradle build` (нужен установленный Gradle 9.5.1+ или Gradle wrapper).
5. Итоговый JAR должен появиться в `mod/build/libs/`.
6. Положите JAR и подходящий Fabric API в папку `mods`.

Версии в `gradle.properties` ориентированы на Minecraft 26.2: Fabric Loader 0.19.5, Fabric API 0.161.0+26.2. Fabric Loom задан как `1.17-SNAPSHOT`; если репозиторий больше не публикует эту snapshot-версию, замените её на актуальную Loom для 26.2 по https://fabricmc.net/develop/.

## Установка данных
- Скопируйте `resourcepack` в `.minecraft/resourcepacks` и включите его.
- Скопируйте `datapack` в `saves/<мир>/datapacks`.
- В мире выполните `/reload`.

## Управление перчаткой
1. Держите перчатку в основной руке и звезду Незера во второй руке.
2. Нажмите ПКМ — одна звезда будет потрачена и заряд добавится к перчатке (максимум 64).
3. Уберите звезду из второй руки и нажмите ПКМ — один заряд расходуется. Снаряд не создаётся.

Это прототип управления, а не точная имитация натягивания арбалета. Код и JSON не были проверены реальной сборкой в этой среде; могут потребоваться небольшие исправления API/форматов при первой компиляции под 26.2.
